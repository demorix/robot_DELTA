# AIVA  
**Artificial Intelligence Voice Assistant**

🌐 **Мова:** [English](README.md) | [Українська](README.ua.md)

AIVA — це освітній AI-проєкт, який розробляється разом зі студентами.  
Метою проєкту є створення повністю голосокерованої інтелектуальної платформи на базі Raspberry Pi з використанням AI-платформи Keyestudio KS0555.

AIVA слухає, розуміє, говорить та автономно приймає рішення, використовуючи сучасні технології штучного інтелекту.

---

## 🚀 Можливості

- 🎤 **Розпізнавання мовлення (STT)** — розуміння голосових команд  
- 🧠 **Велика мовна модель (LLM)** — логічне мислення та прийняття рішень  
- 🗣 **Синтез мовлення (TTS)** — голосові відповіді  
- 👁 **Комп’ютерний зір (CV)** — аналіз навколишнього середовища  
- 🤖 **Автономне прийняття рішень**  
- 🎓 **Освітня спрямованість** — проєкт для навчання студентів  

---

## 🧩 Архітектура системи

AIVA — це мультимодальна AI-система, яка поєднує:
- Голосовий ввід (STT)
- Розуміння мови та логіку (LLM)
- Голосовий вивід (TTS)
- Візуальне сприйняття (CV)

Усі компоненти працюють разом на вбудованому обладнанні в режимі реального часу.
