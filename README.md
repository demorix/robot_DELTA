# AIVA  
**Artificial Intelligence Voice Assistant**

🌐 **Language:** [English](README.md) | [Українська](README.ua.md)

AIVA is an educational AI project developed together with students.  
The goal of the project is to build a fully voice-controlled intelligent platform based on a Raspberry Pi AI system integrated into the Keyestudio KS0555 platform.

AIVA listens, understands, speaks, and makes decisions autonomously using modern AI technologies.

---

## 🚀 Features

- 🎤 **Speech-to-Text (STT)** – understands voice commands  
- 🧠 **Large Language Model (LLM)** – reasoning and decision-making  
- 🗣 **Text-to-Speech (TTS)** – natural voice responses  
- 👁 **Computer Vision (CV)** – visual perception and environment analysis  
- 🤖 **Autonomous decision-making**  
- 🎓 **Educational focus** – designed for students and learning AI systems  

---

## 🧩 System Architecture

AIVA is a multimodal AI system combining:
- Voice input (STT)
- Language understanding and reasoning (LLM)
- Voice output (TTS)
- Visual perception (CV)

All components work together on embedded hardware to create a real-time intelligent assistant.

---

## 🛠 Hardware Platform

- Raspberry Pi (AI-enabled)
- Keyestudio KS0555 AI platform
- Microphone
- Speaker
- Camera module
